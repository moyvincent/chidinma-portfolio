# Chidinma Patricia Igbokwe — Portfolio

A responsive React + Vite portfolio inspired by the Elito reference, using the supplied portfolio content. Includes animated sections, responsive navigation, expandable experience, customer success framework tabs, tool categories, accessible case-study dialogs, email and LinkedIn links, and the full PDF download.

## Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Deploy the `dist` folder to any static hosting service. Contact links and content are in `src/main.jsx`; styling and responsive layouts are in `src/styles.css`.

The hero uses a custom monogram because no portrait was supplied. Customer feedback is paraphrased and anonymised. Case studies are explicitly marked as proposed solutions. No contact form backend or analytics is included. Fonts use Google Fonts, with local sans-serif fallbacks.
